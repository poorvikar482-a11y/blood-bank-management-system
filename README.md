# blood-bank-management-system
Project Description
The Blood Bank Management System is a simple menu-driven application developed using C programming. It helps manage donor details and available blood stock.
The system allows users to register donors, search donors by blood group, update blood stock, issue blood units and view donor reports.
1.Features
- Donor Registration
- Automatic Donor ID Generation
- Age Validation (18–65 years)
- Search Donors by Blood Group
- Update Blood Stock
- Issue Blood Based on Availability
- View All Donor Records
- Display Available Blood Stock
- File Handling for Data Storage

2. Technologies Used
- Programming Language: C
- Header Files: stdio.h, string.h
- Concepts Used:
  - Structures
  - Arrays
  - Functions
  - Pointers
  - Conditional Statements
  - Loops
  - Switch Case
  - File Handling

3. Supported Blood Groups
- A+
- A-
- B+
- B-
- AB+
- AB-
- O+
- O-
4. Main Menu
   1. Donor Registration
   2. Update Blood Stock
   3. Search Blood Group
   4. Issue Blood
   5. Donor Report
   6. Show Blood Stock
   7. Exit

5.  File Handling
The project uses two text files:
- `donors.txt` – Stores donor information.
- `stock.txt` – Stores available blood units.
The files allow the program to load previously saved records when it starts again.

6. Project Objective
The main objective is to develop a basic computerized system for managing blood donor records and blood stock using C programming.
